# Code of Conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. The full text is maintained at that link and is incorporated
here by reference.

## Summary

The Covenant asks everyone who takes part in this project to make participation a
harassment-free experience for everyone, and to act in ways that contribute to an
open, welcoming, diverse, inclusive, and healthy community. In practice that means
being respectful of differing viewpoints, giving and accepting constructive feedback
gracefully, and focusing on what is best for the community. Harassment, insults,
personal or political attacks, and publishing other people's private information
without their explicit permission are not acceptable.

## Scope

The code of conduct applies in all project spaces: the GitHub repository (issues,
pull requests, reviews, commit messages, and discussions) and any other channel used
to work on the project. It also applies when someone represents the project in public
spaces.

## Reporting

Report unacceptable behaviour privately to the maintainer,
[Syed Waleed Ahmed](https://github.com/syed-waleed-ahmed), using the contact options
on the maintainer's GitHub profile. Please do not report conduct issues in a public
issue.

The repository's Security tab ("Report a vulnerability") is for security
vulnerabilities only; see [SECURITY.md](SECURITY.md). Do not use it for conduct
reports.

All reports are reviewed, and the reporter's privacy is respected.

## Enforcement

The maintainer is responsible for clarifying and enforcing the standards and follows
the Contributor Covenant's
[Enforcement Guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines)
(correction, warning, temporary ban, permanent ban) when deciding on a response. The
maintainer may remove, edit, or reject comments, commits, code, issues, and other
contributions that do not align with this code of conduct.
